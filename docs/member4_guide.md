Member 4 – Secure Sandbox & Code Execution Engine

1. Project Overview

The Secure Sandbox 
and Code Execution Engine is responsible for safely executing Python code generated by the Autonomous Multimodal Scientific Discovery Agent.

It provides an isolated execution environment where experimental code can run without directly affecting the host system.

The sandbox captures execution results, errors, and execution status and passes them to the ML evaluation and Statistical Critic components.

2. Objectives

- Execute Python experiment code in an isolated environment.
- Prevent unauthorized access to host files.
- Control execution time and resource consumption.
- Capture standard output and error messages.
- Handle execution failures safely.
- Return structured results to the research workflow.

5. Execution Workflow

1. Receive generated Python code.
2. Validate the execution request.
3. Create an isolated Docker container.
4. Apply security restrictions.
5. Execute the Python code.
6. Monitor execution time and resource usage.
7. Capture output and error messages.
8. Terminate and clean up the container.
9. Return structured execution results.

6. Security Features

The planned security controls include:

- Container isolation.
- Network access disabled by default.
- Non-root execution.
- Read-only filesystem where practical.
- CPU and memory limits.
- Process limits.
- Execution timeout.
- Restricted file access.
- Automatic container cleanup.

7. Error Handling

The executor should handle:

- Invalid Python code.
- Syntax errors.
- Runtime errors.
- Execution timeouts.
- Memory limit violations.
- Container startup failures.
- Unexpected execution failures.

8. Expected Output

The executor will return a structured result containing:

- Execution status.
- Standard output.
- Standard error.
- Exit code.
- Execution duration.
- Error details, if any.

Example:

```python
{
    "result_label": "executed",
    "success": True,
    "stdout": "Experiment completed",
    "stderr": "",
    "exit_code": 0,
    "execution_time": 2.5
}
```

This is an illustrative output format, not an implemented result.
